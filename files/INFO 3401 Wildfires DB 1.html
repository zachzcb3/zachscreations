Source: https://research.fs.usda.gov/firelab/products/dataandtools/us-wildfires

This second query takes the recorded years and sorts them in descending order by the count of their "contained" fire reports for each year, meaning fire reports with an actual containment date to take into calculation as not all fire reports have a confirmed containment date, which doesn't add validity to analysis. The year 2024 is thus shown having fires normally taking the longest to contain. For each year, the average amount of days to contain fires was calculated by using the average value of subtracting the "CONT_DATE" and "DISCOVERY_DATE" variables, which from the dataset are both in datetime format.

query = """
select ((maxx - minx) / 2 + minx) as "Longitude", ((maxy - miny) / 2 + miny) as "Latitude", 
fires.fire_year as "Fire Year",
fires.state as "State",
fires.source_reporting_unit_name as "Source of Report"
from st_spindex__Fires_Shape
join fires on fires.FOD_ID = st_spindex__Fires_Shape.pkid
order by fires.fire_year
"""
df = pd.read_sql_query(query, con = conn)
print(df)

Using GeoPandas and MatPlotLib, this is a final heat-map visualization render taken from using all ~1.4 million data coordinates available within this database. Though it only seems to plot this data up to the year 2010 for some reason, one is able to still deduce the increase in frequency of fire reports in the more recent years, as well as ilustrating which regions of the US are most likely to be affected by rampant wildfires and could worsen in the future. Cooler colors denote later years while warmer colors equate to the more recent years.
